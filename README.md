# Memory Game

Игра на поиск пар: игрок открывает карточки и запоминает их расположение, чтобы найти все совпадения за минимальное число ходов.

## Демо

https://aleks-dizhe.github.io/memory-game-RS-School/

## Функциональность

- Игровое поле 4×4 (16 карточек, 8 пар)
- Случайное перемешивание карточек при старте и при новой игре
- Счётчики: число ходов и число найденных пар
- Логика выбора карточек:
  - первая карточка остаётся открытой до выбора второй
  - совпавшая пара остаётся открытой до конца игры
  - несовпавшая пара закрывается через 700 мс
  - клики по открытым и найденным карточкам игнорируются
- Кнопка «Новая игра» — сброс поля и счётчиков без перезагрузки страницы
- Закрытие модальных окон кнопкой

## Стек

- HTML5
- CSS3
- JavaScript (ES6+), без фреймворков и библиотек
- Вся разметка генерируется через `document.createElement`
